# Storage

The app reads its assets and metadata from `/app0`. It writes settings,
favorites, saved games, records and `app.log` to
`/download0/prosperopuzzles` in the title sandbox. The installed
`PPSA99006` folder is separate from those files.

Keep the title ID when updating an existing installation. Back up saved
games before uninstalling the title or clearing its sandbox storage.

See [Updates](UPDATES.md) for the release installation procedure.
